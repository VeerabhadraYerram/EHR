# Anatomy presentation v2

Body: MakeHuman core base and macro targets, CC0; equal ancestry blend, reference stature, piecewise bone-frame presentation pose alignment and authored high-weight abdominal/hip adiposity envelope (not measured body composition), male/female/neutral and age/weight morph export. https://www.makehumancommunity.org/about/license.html

Organs: Human Reference Atlas / HuBMAP CCF 3D Reference Object Library, Visible Human male/female v1.2, with male pancreatic and liver ducts from v1.1. CC BY 4.0. Contributors include Kristen Browne and the HRA organ illustration team. https://github.com/hubmapconsortium/ccf-3d-reference-object-library . Adaptations: coordinates converted to millimetres, reference-centre registration, combined named compartments/vessels, smooth normals, local heart vessel cropping, illustrative pancreas subdivision/smoothing and deterministic relief of up to approximately 1 mm, and procedural presentation materials. Reference anatomy is not patient imaging.

Shared skeleton, muscles, nerves and brain: BodyParts3D / DBCLS, CC BY 4.0; ../ATTRIBUTION.md. These remain shared reference structures, not sex-specific patient measurements.

Follow-up adaptations: body pose aligned with volume-preserving limb frames; auxiliary pancreatic ducts cropped to local organ bounds for display.
